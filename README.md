# 🚀 Космонавты Казахстана

Тестовое задание для **Windows Touch Panel**, выполненное на **Unity**.

---

# 📖 О проекте

Интерактивная информационная панель, посвященная космонавтам Казахстана.

После запуска отображается **Idle-экран** с анимированным космическим фоном и приглашением **«Нажмите для продолжения»**.

После касания открывается главное меню, где пользователь может выбрать одну из трех карточек космонавтов. При выборе карточки отображается панель с фотографией и краткой информацией.

Основной упор сделан на **отзывчивость интерфейса**, **плавность анимаций** и **чистую архитектуру**.

---

# ✨ Реализованный функционал

* 🌌 Анимированный Idle-экран
* ⭐ Анимированный фон со звездами
* 🎴 Каскадное появление карточек
* 👆 Микроинтерактивность при выборе карточек
* 📄 Плавное открытие и закрытие панели информации
* ⏱ Таймер бездействия с автоматическим возвратом на Idle-экран
* 📦 Передача данных через ScriptableObject
* 📡 Заглушка сервиса отправки UDP-команд
* 🖥 Поддержка Windows

# 🏗 Архитектура

Проект разработан с соблюдением основных принципов **SOLID**.

Используемые подходы:

* Dependency Injection (**Zenject**)
* Dependency Inversion Principle (DIP)
* Event-based взаимодействие (`Action` / `event`)
* Интерфейсы для снижения связанности компонентов
* Разделение данных и логики при помощи **ScriptableObject**

---

# 🎬 Анимации

Все анимации реализованы при помощи **DOTween**.

Используются следующие эффекты:

* Плавное появление Idle-экрана
* Появление заголовка
* Появление надписи «Нажмите для продолжения»
* Каскадное появление карточек
* Микроинтерактивность выбора карточки
* Плавное открытие панели информации
* Плавное закрытие панели информации

---

# ⏱ Таймер бездействия

В приложении реализован сервис отслеживания активности пользователя.

При отсутствии взаимодействия в течение заданного времени приложение автоматически возвращается на стартовый экран.

---

# 📡 UDP

Реализована базовая заглушка сервиса отправки UDP-команд.

Текущая реализация имитирует отправку команды и может быть заменена на работу через `System.Net.Sockets.UdpClient` без изменения остальной архитектуры проекта.
